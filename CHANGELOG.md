# Changelog

All notable changes to this project will be documented in this file.

## [Unreleased]

### Added
- Initial project setup with monorepo structure
- Backend API with Express.js
- Frontend web app with Next.js
- PostgreSQL database with migration setup
- Redis cache and queue system
- Docker and Docker Compose configuration
- GDPR and ISO 27001 compliance framework
- Multi-tenancy architecture
- Magic link authentication system
- Comprehensive API documentation
- Security guidelines and best practices

### In Progress
- Course creation and management system
- User enrollment and progress tracking
- Quiz functionality
- Campaign distribution engine
- Analytics dashboard
- Email integration with SendGrid/AWS SES
- Role-based access control
- Bulk user import
